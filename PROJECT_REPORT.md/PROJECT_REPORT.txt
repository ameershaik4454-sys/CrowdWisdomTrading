# Bitcoin Price and Tweet Sentiment Analysis

## 1. Project Overview

The objective of this project is to explore the relationship between Bitcoin price movements and public sentiment expressed in Bitcoin-related tweets on X (formerly Twitter).

The project combines historical tweet data with daily Bitcoin closing prices, applies sentiment analysis using VADER, aggregates sentiment by date, and uses statistical analysis and visualizations to investigate whether tweet sentiment is associated with Bitcoin returns.

## 2. Objectives

- Obtain historical Bitcoin-related tweet data.
- Obtain historical Bitcoin price data.
- Analyze tweet sentiment using VADER.
- Aggregate tweet sentiment and volume by day.
- Combine daily sentiment measurements with Bitcoin price data.
- Visualize Bitcoin price movements, tweet sentiment, and daily returns.
- Calculate the correlation between daily sentiment and Bitcoin returns.
- Discuss the findings and limitations of the analysis.

## 3. Tools and Technologies

- **Python:** Main programming language.
- **Pandas:** Data cleaning, transformation, aggregation, and analysis.
- **Matplotlib:** Data visualization.
- **VADER Sentiment:** Rule-based sentiment analysis.
- **Apify:** Initial historical tweet collection.
- **Yahoo Finance data via yfinance:** Historical Bitcoin price data.
- **Visual Studio Code:** Development environment.

## 4. Dataset Description

The main analysis uses a historical Bitcoin-related tweet dataset containing 76,797 tweets, covering January 1, 2022, through June 22, 2023.

Historical Bitcoin closing-price data was obtained for the same period. The price dataset contains 538 daily records, which were combined with the daily tweet sentiment measurements.

The project also includes an original Apify collection containing 10 tweets. This smaller dataset was retained separately and was not used as the sole source for the larger historical analysis.

The main processed dataset is:

`data/processed/btc_vader_sentiment_dataset_2022_2023.csv`

## 5. Data Processing

The data processing workflow includes:

1. Loading the historical tweet dataset.
2. Cleaning and converting tweet dates and text fields.
3. Applying VADER to estimate sentiment for individual tweets.
4. Grouping tweets by date.
5. Calculating daily average sentiment and counts of positive, neutral, and negative tweets.
6. Loading daily Bitcoin closing prices.
7. Merging sentiment measurements with Bitcoin prices by date.
8. Calculating daily Bitcoin percentage returns.

The main daily dataset contains the following fields:

- `date`: Date of observation.
- `close`: Bitcoin closing price.
- `average_sentiment`: Average daily VADER compound sentiment score.
- `tweet_count`: Number of tweets recorded for the date.
- `positive_count`: Number of tweets classified as positive.
- `neutral_count`: Number of tweets classified as neutral.
- `negative_count`: Number of tweets classified as negative.
- `daily_return_pct`: Percentage change in the Bitcoin closing price from the previous recorded day.

The first daily return is missing because there is no preceding closing price within the dataset.

## 6. Sentiment Analysis

VADER was used to estimate the sentiment of each tweet based on its text. Its compound score is a normalized measure ranging from -1 to +1.

For this project, tweets were classified as positive, neutral, or negative using VADER's standard compound-score thresholds. The daily average sentiment was then calculated by aggregating the individual tweet compound scores for each date.

Positive values indicate a more positive average sentiment, while negative values indicate a more negative average sentiment. Scores close to zero indicate sentiment closer to neutral on average.

Automated sentiment analysis has limitations. It may misinterpret sarcasm, slang, financial terminology, or the context of a tweet.

## 8. Correlation Analysis and Findings

The relationship between daily average tweet sentiment and daily Bitcoin returns was investigated using Pearson correlation.

The calculated Pearson correlation coefficient was:

**Pearson correlation = 0.0947**

This indicates a very weak positive linear association between average tweet sentiment and same-day Bitcoin returns in the analyzed dataset.

The result suggests that higher sentiment scores were associated with slightly higher daily returns in this sample, but the association was weak. The correlation alone does not establish statistical significance, causation, or predictive ability.

The analysis results were saved to:

`data/processed/price_sentiment_analysis.csv`

The analysis also generated charts showing daily Bitcoin returns and the relationship between sentiment and daily returns.

## 9. Limitations

- Historical tweet datasets may not represent all Bitcoin investors or the wider public.
- The analysis depends on the quality, coverage, and consistency of the available tweet data.
- Automated sentiment scores may not capture sarcasm, context, or specialized financial language accurately.
- Pearson correlation measures linear association and may not capture nonlinear relationships.
- A same-day relationship does not establish whether sentiment precedes price changes.
- The reported correlation does not by itself establish statistical significance or demonstrate that sentiment can predict prices.
- Other factors, including market news, trading activity, macroeconomic conditions, and investor behavior, may influence Bitcoin prices.

## 10. Future Improvements

- Compare today's sentiment with the following day's Bitcoin return.
- Test the statistical significance of observed correlations.
- Examine whether results change across different time periods.
- Compare VADER classifications with manual sentiment labels or another sentiment model.
- Investigate the relationship between tweet volume and market volatility.
- Test alternative sentiment aggregation methods.
- Evaluate predictive models on held-out data before making claims about forecasting performance.

## 11. Conclusion

This project implements a workflow for processing historical Bitcoin-related tweets, estimating tweet sentiment using VADER, merging daily sentiment with Bitcoin closing prices, generating visualizations, and analyzing the relationship between sentiment and price returns.

The analysis produced a Pearson correlation of 0.0947, indicating a very weak positive linear association between daily average tweet sentiment and same-day Bitcoin returns in the analyzed sample.

These findings are exploratory. Further statistical testing and out-of-sample evaluation would be required to determine whether sentiment provides reliable information about subsequent Bitcoin price movements.
